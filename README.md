# 江苏省天一中学高三十九班 · 毕业去向

一个以班级去向表为数据源的响应式交互页面，包含高德底图交互地图、同学名录、数据洞察、个人主页和纪念册导出。

## 运行

```powershell
npm install
npm run dev
```

打开 `http://127.0.0.1:4173/`。

生产构建：

```powershell
npm run build
npm run preview
```

## 静态网站部署

```powershell
npm run build:static
```

构建结果位于 `dist/`，其中只包含可直接部署的 `index.html`、CSS、JavaScript 和图标文件，不需要 Node.js、数据库或后端服务。

同时会生成 `dist/standalone.html`。这是将 CSS、JavaScript 和图标全部内嵌后的单文件版本，可以直接双击打开；标准部署仍推荐上传整个 `dist/` 目录。

可以将 `dist/` 整个目录：

- 上传到 GitHub Pages、Netlify、Vercel、Cloudflare Pages；
- 放入 Nginx、Apache 或宝塔面板的网站根目录；
- 放入任意静态文件空间。

构建使用相对路径，因此部署到网站根目录或 `/graduation/` 等子目录都可以正常加载资源。地图底图需要联网加载；同学资料仍保存在访问者当前浏览器中。

## 地图交互

- 全国层：点击省份轮廓或人数标记进入省份。
- 省份层：点击城市定位点或底部城市索引进入城市。
- 城市层：院校按主要本科校区定位。单人去向点击后直接打开个人主页；多人院校先打开同学名单。
- 当多个院校距离过近时，人数标记会自动防碰撞扇开，并在真实校区坐标保留小定位点，避免文字与标记叠压。
- 支持滚轮、双击、缩放按钮、拖动平移、面包屑返回，以及从个人主页“在地图中查看”直接定位到街道级。
- 地图缩放和平移会自动切换层级：拖动地图后会识别视口中心的省份，放大地图进入该省，再继续放大进入最近城市；缩回国家范围时自动恢复全国视图。
- 地图标记直接联动个人主页；不同校区会按“学校 + 校区 + 坐标”分开显示。
- 当前选中同学在全国、省份和城市地图层级都会保留一个“姓名 + 校区”的个人锁定点，点击可直接返回个人主页；刷新页面后会继续恢复上次查看的同学。

表格与地图使用同一份结构化数据，省份、城市和院校统计不会出现口径差异。

## 个人资料与校区校准

在任意同学主页点击“编辑个人资料”，可修改：

- 姓名、学习专业和个人寄语；
- 智能默认头像或 6 种可选班级形象（青松、晨曦、远海、星夜、书卷、创客）；
- 具体校区名称与完整校区地址；
- 纬度、经度，也可直接点击地图或拖动红色标记完成校准；
- 粘贴高德、Apple 或 Google 地图分享链接，自动读取其中的经纬度并定位；
- 输入或选择已收录校区时，会立即自动填写地址、经纬度并在右侧地图居中定位；例如扬州大学“扬子津校区”会自动切换至华扬西路196号；
- 跨城市校区会同步更新所在城市；例如南京中医药大学“泰州校区”会自动切换为泰州、匡时路6号及对应坐标；
- 编辑器会直接列出当前学校的全部已收录校区，可点击校区标签快速切换；
- 一键恢复学校默认校区位置。

当前 34 所院校共收录 104 个校区、分校区入口。索引通过全国范围校区名称检索和地图 POI 坐标校验生成，作为内置静态数据运行，不依赖页面打开时的外部地理编码服务。若输入的名称不在索引内，保存按钮会保持禁用，必须先通过地图点选或地图链接确认坐标，避免再次锁定到错误位置。

静态默认资料已包含吴运飞的扬州大学扬子津校区和施翰尧的南京中医药大学泰州校区，因此即使访问者首次打开网站、浏览器没有历史数据，也会直接看到这两个已确认位置。

保存后，个人主页、地图标记、校区名称、距离和同校统计会立即更新。资料保存在当前浏览器的 `localStorage` 中，刷新页面后仍会保留；它不会自动上传，也不会跨浏览器或跨设备同步。清除该网站的浏览器数据后，自定义资料会被移除。

保存编辑后的资料时，页面会自动切换到地图并定位到该同学的校区坐标；这个精确位置会持续作为其个人主页和地图标记的锁定位置，不会被学校默认坐标覆盖。

如果浏览器中已经保存了“扬子津校区”等已知校区名称却仍搭配旧校区坐标，页面载入时会自动迁移到正确校区预设，避免继续显示错误位置。

## 数据核对

```powershell
npm run verify:data
```

当前统计口径：

- 55 位同学
- 13 个省级地区
- 34 所院校
- 江苏省内 39 人，占 71%
- 原始去向表中南京 21 人，是人数最多的城市；应用内已确认施翰尧为泰州校区后，默认动态统计为南京 20 人、泰州 1 人

原始姓名和院校来自用户提供的班级去向图；城市、路线距离、省份与院校人数均由同一份结构化数据计算。

扬州大学同学姓名已按用户要求更正为“吴运飞”。

## 主要功能

- 中国去向地图：采用“全国 → 省份 → 城市 → 院校”的逐级视图，避免不同层级的信息同时堆叠。
- 真实底图：Leaflet + 高德中文地图瓦片，缩放后可查看道路、城区和校区周边环境。
- 防叠压点位：城市和院校标记会自动避让，并保留真实坐标锚点。
- 同学名录：姓名/院校全局搜索、省份与院校筛选、排序、分页和详情联动。
- 数据洞察：省份分布、城市集中度、院校集中度、同校同行与最远去向。
- 学生主页：院校、校区、地址、坐标、城市、省份、同校伙伴和从无锡出发的近似距离。
- 高中会议相册：演唱会式圆柱 LED 记忆墙，包含 7 个环绕屏幕、舞台顶棚灯、聚光光束、底座灯环、自动巡演、播放/暂停和本机添加照片。
- 私聊预览：在同学主页打开一对一消息抽屉，消息保存在当前浏览器，便于静态网站展示。
- 纪念册导出：下载一份包含全部 55 位同学的响应式 HTML 纪念册，可直接打印。

私聊当前不是云端实时消息。若需要两台设备之间真正收发私聊，必须接入 Supabase、Firebase、WebSocket 服务或其他后端；静态 GitHub Pages 本身不提供消息存储和身份认证。

院校默认坐标已按各校主要本科校区，用百度地图 POI 地址与点位交叉核对。部分高校有多个校区，实际报到校区以学校通知为准；如默认点与本人校区不一致，可输入已收录校区名称自动匹配，也可直接在地图或链接中校准到具体校区。

## 自动验收

先保持开发服务器运行，再执行：

```powershell
npm run build
npm run verify:data
npm run qa:ui
```

`qa:ui` 使用本机 Google Chrome 进行 Playwright 回归，覆盖：

- 省份轮廓与人数标记切换；
- 城市、院校、多人名单和个人主页链路；
- 从个人主页定位到院校街道级；
- 桌面、平板、手机布局；
- 城市与院校标记重叠检测；
- `吴运飞` 姓名核对；
- 个人资料编辑、地图点选校准、即时更新与刷新后持久化；
- 控制台错误与横向溢出检查。

截图和验收结果保存在 `preview/`。

## 技术说明

- React 19 + Vite 8
- Leaflet 1.9
- 高德地图中文瓦片（`webrd0{s}.is.autonavi.com`）
- 地图版权归属高德地图；底图需要联网加载。离线时院校与省份交互点仍会保留，并显示底图加载提示。
